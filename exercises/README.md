# Exercise workbook

Each created lesson has six exercises in section 17: three beginner, two intermediate, and one challenge. Write an answer before revealing section 18. Include units, predicted shapes, and reasons for each operation. For code exercises, try one ordinary input and one boundary case.

Keep personal responses in your own copy of the notebook or a separate study journal. The repository's PROGRESS.md measures construction status, not your mastery.

## Cross-lesson practice

A fictional stall sells four orders: products A, B, A, B; quantities 2, 1, 3, 4; unit prices 10 and 20. Describe the observation unit and schema. Compute totals manually, reproduce them with NumPy and pandas, draw a labeled chart, and explain two conclusions that the data cannot support.

Then suppose tomorrow's demand must be predicted before the shop opens. Identify which columns would be available, choose a constant baseline from earlier days, and describe a chronological evaluation. A report that includes correct arithmetic but uses tomorrow's final sales as an input fails the exercise.
