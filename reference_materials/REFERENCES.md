# Primary references

The lessons are original explanations and examples. These official resources support API details and provide deeper reference material; they do not replace the academy's worked lessons.

- [Python virtual environments](https://docs.python.org/3.11/library/venv.html): interpreter isolation and direct interpreter invocation.
- [Jupyter installation](https://jupyter.org/install): Notebook installation and launch conventions.
- [nbclient notebook execution](https://nbclient.readthedocs.io/en/latest/client.html): programmatic execution used by the verification scripts.
- [NumPy beginner guide](https://numpy.org/doc/stable/user/absolute_beginners.html): shapes, axes, indexing, and arrays. Consult documentation matching the installed version when behavior differs.
- [pandas introductory tutorials](https://pandas.pydata.org/docs/getting_started/intro_tutorials/index.html): labeled tables, selection, and combination.
- [Matplotlib quick start](https://matplotlib.org/stable/users/explain/quick_start.html): figures, axes, and plotting operations.
- [scikit-learn common pitfalls](https://scikit-learn.org/stable/common_pitfalls.html): consistent preprocessing, leakage, and reproducibility.

The environment and notebook reports record actual local behavior; an upstream documentation page is not evidence that a local notebook was executed.
