# Learn the academy actively

Start with [START_HERE.md](START_HERE.md). Use the eight-lesson preview to see the destination, then work through the numbered Python foundations. A prerequisite marked planned has not been authored yet: consult [PROGRESS.md](PROGRESS.md) rather than treating its module specification as a tutorial.

For a two-hour study session, spend about 20 minutes reading intuition and terminology, 20 minutes doing the hand calculation, 30 minutes running and explaining code, 35 minutes attempting exercises, and 15 minutes reviewing mistakes. Adjust these times when an idea needs more practice. Studying consistently matters more than finishing a large list quickly.

Before running a cell, write a prediction of its output. After running, explain any difference. Change one value, predict again, and observe. Restart the kernel and run all cells when finished. Make experiments in a personal copy so the clean source lesson remains reproducible.

Attempt section 17 before opening section 18. A solution you can recognize is not necessarily a solution you can produce. The next day, redo a missed exercise without looking. Each week, explain one concept in plain English and reconstruct one small calculation from a blank notebook.

Keep a private folder named `personal_notes` for your learning journal; it is ignored by Git. Use this entry format:

```text
Date and lesson ID:
Concept explained in my own words:
Manual calculation, including units:
Output prediction and actual result:
One experiment and what it taught me:
Exercises attempted without solutions:
Mistake, cause, and corrected reasoning:
Question to revisit:
Next review date:
```

Use [the assessment rubric](assessments/README.md) to assess understanding. Aim to explain the idea, compute the tiny example, implement the core operation, and diagnose a changed-input failure. Repository verification records software construction, not your mastery; keep those two kinds of progress separate.

The [36-week plan](STUDY_PLAN_36_WEEKS.md) is the recommended core route. The [12-week plan](STUDY_PLAN_12_WEEKS.md) is an intensive introduction with later study still required. Neither schedule promises mastery of every advanced extension in the 427-notebook inventory.
