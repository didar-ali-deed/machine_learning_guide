# 12-week intensive study plan

Budget 15–20 focused hours per week. This is an intensive introduction to the classical ML workflow, not an entire university program condensed without loss. A complete programming beginner should normally choose the [36-week route](STUDY_PLAN_36_WEEKS.md). Advanced topics and most specialized algorithms require later study, and planned notebooks may not yet be available.

| Week | Study focus | Required evidence |
|---:|---|---|
| 1 | First three orientation lessons; Python essentials | Run a clean notebook and explain each line of a baseline |
| 2 | NumPy, pandas, plotting | Shape checks, safe joins, and interpretable charts |
| 3 | Algebra, vectors, derivatives, probability basics | Hand calculations with units and numerical verification |
| 4 | Preprocessing, splits, generalization | Leakage-free pipeline and baseline report |
| 5 | Linear regression, MSE, gradient descent | Derive the gradient and compare scratch/library results |
| 6 | Regularization and logistic regression | Validation analysis and threshold-aware evaluation |
| 7 | KNN, Naive Bayes, decision trees | Explain assumptions and compare on identical splits |
| 8 | Forests, SVMs, boosting | Justified model comparison and failure analysis |
| 9 | Cross-validation, search, uncertainty | Training-fold search with a reserved final test |
| 10 | K-Means, PCA, DBSCAN | Explain geometry, scaling, and unsupervised evaluation limits |
| 11 | One small capstone; interpretation and ethics | Reproducible baseline, model, and limitations report |
| 12 | Local prediction interface and final review | Rerun the complete workflow and defend choices orally |

Reserve at least one third of each week for exercises and debugging. If week three's manual calculations are unclear, extend the plan; later optimization cannot be understood by memorizing API calls. Use the [rubric](assessments/README.md) rather than calendar pressure as the progression rule.

After these twelve weeks, continue probability and statistical inference, time series, neural networks and PyTorch, deep learning, NLP, vision, recommendations, RL, advanced paradigms, responsible ML, and MLOps. The [full syllabus](SYLLABUS.md) preserves those topics instead of pretending this route covers them in depth.
