# 36-week beginner study plan

Budget 8–12 hours each week: roughly one third explanation and manual calculations, one third implementation and experiments, and one third exercises and review. This is a core route with advanced orientation, not a promise to master all 427 planned notebooks in 36 weeks. The full inventory is substantially longer. Many scheduled lessons remain planned; check [PROGRESS.md](PROGRESS.md) before each week.

| Week | Focus | Deliverable and readiness check |
|---:|---|---|
| 1 | ML meaning, types, datasets, Jupyter | Annotated toy table and a manually evaluated baseline |
| 2 | Variables, types, operators, strings | Small checked calculations with explicit units |
| 3 | Containers, conditions, loops | Summarize records without pandas |
| 4 | Functions, scope, modules, exceptions | Reusable functions with boundary-case checks; revision week |
| 5 | Files and classes; NumPy arrays | Explain indexing, shape, and vectorization |
| 6 | pandas, grouping, merging | Reconciled data-quality and aggregation report |
| 7 | Visualization and exploratory analysis | Three justified charts with limitations |
| 8 | Arithmetic, equations, functions | Hand-solved numerical examples and graph interpretation |
| 9 | Vectors, matrices, products, norms | Trace shapes and units in weighted predictions |
| 10 | Derivatives, chain rule, gradients | Derive a quadratic update and inspect step sizes |
| 11 | Probability, conditional probability, Bayes | Explain a small frequency table without formulas alone |
| 12 | Statistics, sampling, uncertainty | Foundation assessment and repair weak prerequisites |
| 13 | Splits, missingness, encoding, scaling | Train-only preprocessing pipeline |
| 14 | Generalization, baselines, bias/variance | Written experimental protocol and learning curves |
| 15 | Simple/multiple linear regression, OLS | Scratch/library agreement and residual explanation |
| 16 | Batch, stochastic, mini-batch descent | Compare updates while controlling initialization |
| 17 | Ridge, Lasso, polynomial features | Validation experiment showing complexity tradeoffs |
| 18 | Logistic regression and thresholds | Derive sigmoid and interpret classification errors |
| 19 | KNN and Naive Bayes | Compare distance and probability assumptions |
| 20 | Decision trees and pruning | Explain a split by hand and control overfitting |
| 21 | Random forests and bagging | Compare a tree to an ensemble on fixed splits |
| 22 | SVMs and gradient boosting | Explain margins versus sequential error correction |
| 23 | Cross-validation and hyperparameter search | Search inside training folds; reserve a final test |
| 24 | Error analysis, imbalance, uncertainty | Classical ML assessment and revision |
| 25 | K-Means and DBSCAN | Compare cluster geometry and sensitivity to scaling |
| 26 | PCA and dimensionality reduction | Explain reconstruction and variance retention |
| 27 | Anomalies and chronological forecasting | Compare simple baselines with appropriate time ordering |
| 28 | Bayesian uncertainty orientation | Distinguish confidence, probability, and calibration |
| 29 | Neural network mechanisms | One manual backpropagation and a NumPy network |
| 30 | CPU PyTorch and training loops | Reproduce the NumPy mechanism with autograd |
| 31 | CNNs, attention, NLP/vision orientation | Trace shapes in one small chosen application |
| 32 | Recommenders and RL orientation | Explain exposure bias and a Bellman update; select later specialization |
| 33 | Interpretability, ethics, robustness | Audit subgroup behavior and explanation limitations |
| 34 | Local serving and reproducibility | Tested prediction interface and artifact documentation |
| 35 | One tabular capstone | Baseline, tuning, untouched-test evaluation, and report draft |
| 36 | Capstone review and next specialization | Reproduce results from a clean environment and defend limitations |

Every fourth week includes revision even when a topic is listed. If the readiness check fails, repeat the prerequisite rather than compressing the next topic. Advanced forecasting, probabilistic inference, modern language models, RL, and production operations each deserve additional study after this route. Complete the other eight capstones over subsequent months.

Choose an application only after you can explain its baseline, data split, and metric. Keep a weekly journal with one concept you can now teach, one mistake you corrected, and one unresolved question.
